# useful-userscripts

## 📜 Scripts

### lowercase-youtube-titles

Rewrites every video title across YouTube into lowercase — homepage, search, sidebar, watch page, and player overlay included.

---

## 🚀 Installation
 
1. Install a userscript manager: 
- [Tampermonkey](https://www.tampermonkey.net/)
- [Violentmonkey](https://violentmonkey.github.io/)

2. Click the raw link for the script you want (or open the `.user.js` file above and click **Raw**).

3. Your userscript manager will detect the file and prompt you to install it. Confirm, and you're done. ✅
